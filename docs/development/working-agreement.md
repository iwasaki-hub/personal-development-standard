# Working Agreement

## 開発の約束
- 安全性 > 再現性 > 速度。ただし反復作業は可能な限り自動化する。
- 1タスク1PR、小さく戻しやすい変更を優先する。
- `main` 保護と必須チェックをGitHub Rulesets/Branch protectionで設定する。
- CI成功は「当該チェックが成功」の意味だけ。実機や権限テストを代替しない。

## 役割
- ChatGPT: 要件整理、タスク分解、リスク検討、レビュー支援。
- Codex: 許可された範囲の実装、検証、PR作成、正確な報告。
- GitHub: 履歴、CI、Review、Merge制御。
- 人間: 本番公開、DB変更、重要権限変更、Mergeの最終決定。

## Definition of Ready
- 目的、範囲、対象外、受け入れ条件、検証方法が具体的。
- 破壊的操作や環境依存を洗い出した。

## Definition of Done
- 受け入れ条件が満たされ、必要なテスト結果が記録されている。
- 差分と秘密情報を確認し、PR本文にリスクとロールバックがある。
- Review承認と必要なCIが完了してからMerge。
- 公開は別の承認ゲートを通る。
