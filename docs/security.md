# Security & Privacy

## 秘密情報
- `.env` はコミットしない。公開可能な設定値のみ `.env.example` に記載。
- クライアント公開環境変数にシークレットを入れない。
- CIの権限は最小限。外部PRに本番シークレットを渡さない。

## アクセス制御
- 認証・認可はサーバー/DB側で検証する。画面側の制限だけに頼らない。
- 共有環境・Productionへの書き込みは承認、監査、ロールバック方針を定義する。

## データ保護
- 収集データ、保持期限、削除方針をプロジェクトごとに定義。
- 個人情報・トークンをログ・Issue・PRに貼り付けない。

## インシデント手順
1. 新規公開・変更を止める。
2. 影響範囲を確認し、認証情報を必要ならローテート。
3. 人間の承認のもと復旧し、再発防止を記録。
